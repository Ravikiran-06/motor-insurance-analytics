# Motor Insurance Claims & Policy Analytics Dashboard

An industry-grade Data Analytics & Business Intelligence platform that transforms raw motor insurance data streams into clean analytical assets, surfaces dynamic pattern insights, and deploys via an interactive web interface.

## 🛠️ Technology Stack
* **Language Backend:** Python (Pandas, NumPy)
* **Visualization Layer:** Matplotlib, Seaborn
* **Frontend Web Framework:** Streamlit
* **Verification Suite:** Pytest
* **Container Layer:** Docker
* **Target Cloud Architecture Flow:** AWS (ECR -> IAM -> EC2 Endpoint Deployment)

## 🚀 Local Run Execution Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Launch the application: `streamlit run app/streamlit_app.py`
3. Execute the unit verification suite: `pytest`
